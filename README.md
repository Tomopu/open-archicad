# Open ArchiCAD

ブラウザで動く、徹底的に軽量な建築 CAD。フレームワーク不使用(Vanilla TypeScript + Canvas 2D)、
3D 表示用の Three.js は 3D タブを開いた時のみ遅延読み込みされます。描画は変更時のみ行い、
常時レンダリングループを持ちません。

## 起動方法

### Docker(推奨)

```bash
docker compose up -d --build
# → http://localhost:8080
```

### 開発サーバー

```bash
npm install
npm run dev
```

## 機能

### 2D 図面設計(JIS A 0150 平面表示記号に準拠)
- **壁**: 厚さ・高さ・構造壁(塗りつぶし)指定、連続入力、Shift で水平垂直。
  接合部(L字・T字)は自動的にきれいに結合。厚さはプロパティでいつでも変更可(複数選択で一括変更)
- **柱**: 角柱・丸柱(寸法指定、2D は構造断面塗り、3D にも反映)
- **建具の位置確認**: ドア・窓の配置時とドラッグ中に、壁の両端からの距離(mm)をリアルタイム表示
- **建具**: 片開き戸 / 両開き戸 / 引違い戸 / 片引き戸 / 折りたたみ戸、
  引違い窓 / はめ殺し窓(FIX) / 片開き窓 — 壁上クリックで配置、`F` 内外反転・`G` 吊元切替
- **階段**: 直進 / かね折れ(L) / 折返し(U) / 螺旋 — 段数・踏面・蹴上げ・幅を指定、昇り矢印付き
- **家具**: ベッド・テーブル・ソファ・キッチン・便器・浴槽・洗面台・冷蔵庫・洗濯機・収納 ほか
- **設備**: 給湯器/ボイラー・換気扇(24h換気)・住宅用火災警報器・エアコン・分電盤・電気温水器
- **寸法**: 建築式の端末記号(斜線)付き寸法線
- **部屋・エリア**: **長方形(2点・既定)/ 鉛筆(多角形)** の 2 モードで領域指定、名称・用途ラベル、面積(m²・帖)自動表示
- **植栽・人物**: 樹木・低木・人物(2D 記号 + 3D 表示)

### 鉛筆ツール(SketchUp 流スケッチ)
- **鉛筆 `L`**: クリックで線を描き、**閉路ができると自動的に面**になる。辺の途中(線上スナップ)からも線を引ける
- **長方形モード**: 2点(対角)クリックで長方形。部屋ツールと共通で、
  **カーソル上の ✎ / ▭ アイコン**または `Tab` でモード切替。ガイド・寸法表示も部屋ツールと共通
- **数値入力**: 作図中にキーボードで `3640,2730` + Enter → その寸法で確定(線は長さ指定)
- **面の押し出し**: 3D で面の中心の**円錐つまみ**をドラッグ → 立体化(高さ変更、0 で平面に戻る)
- **面の中に面**: 面の内側に線で閉路を作ると入れ子の面になり、**立体では外側を底面まで貫通**。
  内側の立体は独自の高さを持てる。**消しゴムアイコン**で面だけ削除(貫通穴)。内側の線を消せば 1 つの面にマージ
- **クリックで選択を絞り込み**: 1回=スケッチ全体 → 2回=面 → 3回=閉路 → 4回=辺。**辺ごとに色**を設定可能
- 作図中の `⌘Z` は**今引いている線だけ**を取り消す(壁・部屋・寸法も同様)/ `Esc` で選択ツールへ戻る
- 部品スタジオにも鉛筆あり: 地面に多角形を描いて押し出しパーツに(2点で長方形)

### 壁の基準線(通り芯)
壁の中心線(基準線)を**一点鎖線**で表示。壁ツールのオプションで**基準線から右側 / 左側に何mm**かを
設定でき(ロックで左右連動)、クリックした線=通り芯として壁本体をオフセット配置できます。

### 基準点複写・オブジェクト一覧・ガイド設定
- **基準点複写**: 複製アイコン → 十字カーソルで基準点をクリック(端点・交点に吸着)→
  距離表示・水平垂直/45°ガイド付きで配置。右クリックでキャンセル(選択ツールへ)。**3D・部品スタジオでも同様**
- **オブジェクト一覧**(右パネル): 全要素をリスト表示。**目のアイコンで表示 / 非表示**、
  クリックで選択・**Shift+クリックで範囲選択**(1番目と5番目を選ぶと間もすべて選択)。
  グループは**ブロック表示**(インデントした子・折りたたみ・一括表示/非表示・グループ解除ボタン)。
  **ダブルクリックでリネーム**(グループ名も)
- **視点メニュー**(右上): 全項目が常に見えるカスタムメニュー。
  **2D**: 平面図と **2D の立面図(正面・背面・左右側面)** — 立面図は壁から自動生成され、
  開くと建物が**画面中央に自動フィット**。同じ高さの壁はひとつのシルエットにマージされ接合部が綺麗に繋がる。
  複数棟あるときは画面上部のチップで**どの建物か**を選択。
  立面図は**編集可能**: クリックで壁・建具を選択(プロパティ編集)、ドラッグで水平移動(スナップガイド付き)、
  **壁の上端をドラッグで高さ変更**、窓は上下ドラッグで窓台高(壁端からの距離・窓台高を寸法表示)。
  **壁・ドア・窓ツールでの新規配置**も可能(窓はクリックした高さ = 窓台高) / **3D**: 南西・南東・北西・北東アイソメ
- **ガイド ▾**(ステータスバー): 端点・中点・中心・図心・交点・仮想交点・延長・線上の各スナップを個別に有効 / 無効。
  **延長ガイドはグリッドの角点で一旦止まる**
- **3D・部品スタジオでも 2D と同じ作図体験**(共通モジュール): 十字カーソル・スナップガイド・
  ライブ描画線・**青い寸法ラベル**・**X/Y 軸平行ガイド**(赤 / 青)・**始点から 1 辺目と垂直方向の
  延長ガイド**(3 辺目で長方形を閉じやすい)。計測ツールは**オレンジの十字 +
  メジャーアイコン + リアルタイム距離表示 + スナップ**対応
- **3D の選択ツール**: 空の場所を**左ドラッグで範囲選択**。**Space 押下中は視点操作モード**
  (手のカーソル・左ドラッグで回転)— 2D・3D・部品スタジオ共通。鉛筆ツール中は鉛筆カーソル。
  複数選択の 90° 回転は**全体の中心で回る**ので形が崩れない
- **スケッチの選択サイクル**: 1 クリック = **面** → 2 回目 = **閉路の辺** → 3 回目 = **全体**
  (4 回目以降はロックされ、移動中に選択が切り替わらない)。閉路選択中は**辺をホバーで強調**、
  クリックでその辺だけを選択。辺の端点つまみは**接続している辺と一緒に動き**、並行位置の辺は変わらない
- **鉛筆の数値入力は 2D・3D・部品スタジオ共通**: 2 点目以降は数字 + Enter でその長さの辺
- **3D の面プッシュ / プル**: 選択済みの箱系オブジェクトをもう一度クリックすると**その面を選択**、
  ドラッグでその面だけを伸縮(反対面は固定)。角つまみも**反対の角を固定**して伸縮(2D と同じ)
- **スケッチ(鉛筆)の 3D 編集**: 辺の**端点つまみ**で形を変更、各面の**円錐つまみ**で押し出し。
  部品スタジオの多角形パーツにも**頂点つまみ**(緑)と角つまみあり
- **基準点複写は 3D・部品スタジオでも同じフロー**: 基準点選択中は十字+スナップガイド、
  配置前は**半透明ゴースト**がカーソルに追従。右クリックでキャンセル
- **家具と設備は 1 つのツールに統合**(ツール設定のカテゴリで切替)。設備も家具同様に**リサイズ可能**
- 壁プロパティでも**基準線→右 / 左**を編集可能(鎖アイコンの**連動ロック UI**)

### 階層(複数フロア)
トップバーの階タブ(1F / 2F / ＋)で階を切替・追加できます。ダブルクリックで名前変更、右クリックで削除。
上階では**下階が透かして表示**され(オン/オフ可)、**「下階の壁をコピー」**で外周壁・柱を一発複製できます。
**各階の階高**はプロジェクト設定で指定でき(未設定は壁高から自動)、3D では**上階・下階を個別に非表示**にできます。
3D で編集できるのは**いま選んでいる階のオブジェクトのみ**(誤選択防止)。1F と 2F の境界には薄い点線が入ります。
リーガルチェックも多層対応(容積率=全階合計、建蔽率=1階、警報器・採光は各階ごと)で、
結果クリックで該当の階へ自動的に切り替わります。

### 3D モデル
平面図から自動生成(壁の開口・窓ガラス・まぐさ・腰壁、階段の段板、家具、植栽・人物、鉛筆スケッチの立体)。
**全階を積層した一棟まるごとの 3D** が生成され、壁の接合部は 2D と同じルールで隙間なく結合されます。
マウスで回転・パン・ズーム。グリッドは**平面図と同じ位置・同じ幅**で表示され、1 グリッドを 4 等分する点線付き。
**ワイヤーフレーム表示**と**輪切り(断面)表示**(スライダーで切断高さを調整)にも対応。

### カラー・部品スタジオ
- **カラーパレット**: 壁・部屋・家具・柱・階段・自作部品に単色を設定可能。プロパティの色スウォッチから
  プリセット/保存パレット/履歴/HEX・RGB 入力/ネイティブピッカー/**スポイト**(対応ブラウザ)で選べます
- **部品スタジオ**(コンポーネント → 3D作成): 箱・円柱・球・円錐を**合成/くり抜き(CSG)**して
  オリジナル 3D 部品を作成。左のアイコンレールからパーツを追加し、クリック選択 → ドラッグ移動、
  **つまみで寸法変更**、選択パーツの上に**複製・回転(15°刻み、数値入力で任意角)・削除**のアイコンを表示。
  2D 図面記号(矩形/円)とラベルを設定してコンポーネントに保存でき、保存後も**✎ ボタンで再編集**できます。
  平面図には記号、3D には作成したメッシュが表示されます。CSG ライブラリは遅延読み込みです

### 自動保存
編集内容は自動的にブラウザへ保存され、**リロードしても消えません**(「新規」でクリア)。

### マテリアル(仕上げ)・テクスチャ
壁・部屋(床)・家具・柱・階段に**仕上げ**を設定できます(プロパティの「仕上げ」)。
白仕上げ・コンクリート・木(明/濃)・レンガ・タイル・畳・石・芝生・ガラスの10種。
テクスチャは**実行時に Canvas で生成**するため画像アセットゼロで軽量です。
2D では部屋の床色に薄く反映され、3D ではテクスチャ付きで表示されます。

### 3D 直接編集・モデリング
3D ビューでオブジェクトを**クリックして選択、そのままドラッグで移動**できます(グリッドスナップ付き。
オブジェクトを掴んでいる間、カメラは動きません)。**配置ツールを選んだまま 3D の床をクリックすると
その場に配置**され、ドア・窓は 3D の壁を直接クリックして取り付けられます。
編集は 2D 図面と同じデータなので**即座に平面図へ反映**され、右パネルのプロパティ編集・Delete 削除・Undo も
3D 表示のまま使えます。空クリックで選択解除、空間のドラッグはカメラ操作のままです。

3D ツールバーから **＋箱(汎用ボックス)** を床クリックで配置でき、**上面をドラッグすると
プッシュ/プルのように高さが変わります**(壁・柱・家具も同様)。回転・削除ボタンも 3D 用に用意。
数値での寸法変更は右パネルのプロパティからいつでも可能です。

選択した家具・柱には**3D ギズモ**が表示されます: 赤=幅 / 緑=奥行 / 青(円錐)=高さ /
紫(球)=**浮かせ**(棚や吊り戸棚のように宙に浮かせる)。ドラッグ中は寸法がカーソル横に表示されます。
左のツールパレットは 3D でもそのまま使え、壁・ドア・窓・家具などを 3D 上でクリック配置できます
(寸法・部屋など 2D 専用ツールは 3D 中はグレーアウト)。

配置ツールを選ぶと **3D 上にゴーストプレビュー**が表示され、クリックで確定します。
壁は始点に細いポールが立ち、1回目のクリック後は**カーソルまで伸びる半透明の壁と長さ(mm)**が
リアルタイムに表示されます。部屋・寸法ツールも 3D の床クリックで使えます。

窓・ドアは 3D でクリック選択でき、**壁に沿ってドラッグ**(壁の外には出ない)、
窓は**上下ドラッグで取付高さ(窓台高)**も変えられます。ドラッグ中は壁両端からの距離と
床からの高さを表示。2D 図面には腰窓の**「h=900」表記**(実務図面の腰高添記)が入ります。

3D CAD 補助機能: **計測**(2点クリックで距離、ラベルは線の中点上に表示)/ **PNG 書き出し** /
**視点プリセット**(上・正面・側面・鳥瞰)/ **上階・地面の表示切替** / **XYZ 軸の表示切替**(太い無限長スタイル)。
Shift+クリックで**複数選択**。つまみの上では「つかむ手」カーソルになり、移動中はつまみも一緒に追従します。
壁は両端の長さつまみ・厚みつまみ・高さ円錐で GUI 変形でき、テクスチャは**実寸基準**なので開口を動かしても伸び縮みしません。
選択時のアクションアイコン(回転・複製・グループ化・削除)は 3D でもオブジェクトの上に表示されます。

**グループ化**: 複数選択するとアクションバーにグループ化アイコンが現れ、ワンクリックで
グループ化/解除。グループはクリックでまとめて選択され、2D/3D どちらでも一緒に動きます。

パフォーマンス: ドラッグ中はシーンを再構築せずメッシュのみ平行移動し、確定時に 1 回だけ再構築します。
古いジオメトリは GPU から明示的に解放し、高 DPI 環境ではピクセル比を 2 に制限しています。

### 画面表示・操作
- 右下に**地図スタイルの縮尺バー**(1グリッド = グリッド幅 の表記付き)
- **グリッド幅はステータスバーで自由に変更可**(スナップ候補も自動で追従、半グリッドの補助線を表示)
- オブジェクト選択時に**回転 ⟳・複製 ⧉・ゴミ箱(削除)のアイコン**がオブジェクトの上(縦長なら横)に表示
- 選択時にオブジェクトの下へ**寸法チップ(長さ・幅など)**が表示され、**数値をクリックするとその場でキーボード入力して直接編集**できる
- 選択ツールで**範囲選択**: 左→右ドラッグ = 完全に囲んだ要素、右→左ドラッグ = 触れた要素すべて(まとめて移動・編集・削除)
- 部屋(エリア)の作図中は**各辺の長さと面積をリアルタイム表示**
- 壁の端点に吸着したときは**緑の○**でスナップ先を表示
- 選択オブジェクトに**変形ハンドル**(濃青の四角)が表示され、掴んでドラッグで変形できる:
  壁=両端点(Shift で直交)+**長辺側の厚みハンドル** / 部屋=各頂点 / 家具・柱=4隅(反対の角を固定して幅・奥行)/ 階段=幅 / ドア・窓=両端(幅)
- 厚みの違う壁同士の接合も、相手の厚みに合わせて延長するため段差・欠けが出ない(2D/3D 共通)
- **グループ選択中にメンバーをもう一度クリック**すると、その要素だけに選択が絞られる(2D/3D 共通)
- **入れ子の部屋は重複面積を自動で差し引き**、外側の部屋のラベルは内側の部屋を避けた位置に表示
- 部屋・文字は**ダブルクリック**または寸法チップの「名前」から直接リネーム
- ドア・窓の**配置中に R / F で内外反転、G で吊元切替**

### コンポーネント
選択した要素群を名前を付けて登録 → ワンクリックで複製配置。
JSON 書き出し/読み込みで**他のファイル・他の PC と共有可能**。ブラウザに永続保存。

### リーガルチェック(簡易)
- 建蔽率・容積率(建築基準法 52・53 条)
- 居室の採光 1/7・換気 1/20(法 28 条)
- 階段の蹴上げ・踏面・幅(施行令 23 条)
- 廊下の有効幅(施行令 119 条・参考)
- 住宅用火災警報器の設置(消防法 9 条の 2)
- 24 時間換気(シックハウス対策・施行令 20 条の 8)
- 火気使用室の内装制限(法 35 条の 2・注意喚起)

> ※ 設計参考用の簡易チェックです。法適合の最終判断は建築士・特定行政庁・指定確認検査機関にご確認ください。

## 操作方法

| 操作 | 方法 |
|---|---|
| ツール切替 | `V` 選択 / `W` 壁 / `C` 柱 / `D` ドア / `N` 窓 / `S` 階段 / `F` 家具 / `E` 設備 / `P` 植栽 / `M` 寸法 / `T` 文字 / `A` 部屋 / `L` 鉛筆 |
| モード切替 | `Tab`(部屋・鉛筆: 長方形 ⇄ 多角形 / 階段: 形状) / `Esc` 選択ツールへ |
| パン(視点移動) | 右ドラッグ / 中ボタンドラッグ / Space+ドラッグ / トラックパッド2本指スクロール / Shift+ホイール |
| ズーム | マウスホイール / ピンチ |
| 回転 | `R`(配置プレビュー・選択要素) |
| 削除 | `Delete` / `Backspace` |
| 元に戻す / やり直し | `⌘Z` / `⇧⌘Z` |
| 保存 | `⌘S` |
| スナップ | ステータスバーで 910 / 455 / 100 / 10 mm 切替(尺モジュール) |

サイドメニューはキャンバスの上に浮いており、境界ドラッグで幅を変更できます(図面はリサイズされません)。
幅 0 まで縮めると折りたたまれ、画面の左上/右上に ☰ アイコンが表示されます。アイコンのクリックか、
